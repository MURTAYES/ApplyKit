# Phase 03 Plan 02: Dependent Select Engine + FillEngine Integration

**Phase:** 03-dropdown-matching-dependent-selects
**Plan:** 02
**Requirements:** `DROP-01`, `DROP-03`, `DROP-04`

## Objective
Implement dependent select sequencing (observing and waiting for dynamically loaded child options e.g. District $\rightarrow$ Upazila) and integrate dropdown matching into the core `fillEngine` pipeline.

## Tasks

### Task 1: Dependent Select Waiter (`src/engine/dependentSelects.ts`)
- Implement `waitForSelectOptions(selectEl: HTMLSelectElement, timeoutMs = 1000): Promise<boolean>`:
  - Uses `MutationObserver` on `selectEl` to detect newly added `<option>` nodes.
  - Includes fallback polling every 50ms until options appear or timeout expires.
  - Resolves `true` when non-placeholder options are present, `false` on timeout.
- Implement helper to detect dependent pairs (e.g. `district` field leading to `upazila` / `thana` / `p.s.` field in the same section).

### Task 2: FillEngine Updates (`src/engine/fillEngine.ts`)
- Query `<select>` elements in addition to `<input>` and `<textarea>`.
- Order execution such that parent dropdowns (District) are filled first, followed by awaiting dependent child dropdowns (Upazila), before matching child options.
- Check non-overwrite safety: If select is already set to a non-placeholder option, skip and mark `skipped_user_filled` (R5).
- If profile has no data, mark `skipped_empty_profile`.
- If no confident match found, leave untouched and mark `unmatched`.
- If match found, apply `setNativeSelectValue` and mark `filled`.

### Task 3: Content Script Update (`entrypoints/content.ts`)
- Update message listener to handle async `await executeFill(...)` and return the structured `FillReport`.

### Task 4: Tests
- Create `tests/engine/dependentSelects.test.ts` testing MutationObserver / timeout dynamic option loading.
- Create `tests/engine/fillEngineDropdowns.test.ts` testing end-to-end form autofilling containing inputs, textareas, native selects, and dependent cascading selects.

## Verification
- Run `npm run test` and verify 100% pass across all test suites.
- Run `npm run build` and ensure extension compiles cleanly with zero errors.
