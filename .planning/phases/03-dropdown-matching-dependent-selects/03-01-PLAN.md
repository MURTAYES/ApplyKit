# Phase 03 Plan 01: Bilingual Dictionaries + Dropdown Option Matcher

**Phase:** 03-dropdown-matching-dependent-selects
**Plan:** 01
**Requirements:** `DROP-01`, `DROP-02`, `DROP-04`

## Objective
Implement comprehensive bidirectional bilingual dictionaries (English $\leftrightarrow$ Bangla Unicode) and a robust option matcher for native `<select>` dropdowns that performs normalized text comparison, alias expansion, and confidence scoring.

## Tasks

### Task 1: Bilingual Dictionaries (`src/engine/dictionaries/`)
- Create dictionaries for:
  - Districts (all 64 BD districts with common spelling variants in English and proper Bengali Unicode)
  - Education Boards (Dhaka, Chattogram/Chittagong, Rajshahi, Cumilla/Comilla, Sylhet, Barishal/Barisal, Dinajpur, Jashore/Jessore, Mymensingh, Madrasah, Technical)
  - Religions (Islam, Hinduism, Buddhism, Christianity, Other)
  - Genders (Male, Female, Other)
  - Result Types (First/Second/Third Division, GPA out of 5, CGPA out of 4)
  - Quotas (Non-Quota, Freedom Fighter, etc.)
- Create unified dictionary resolver `lookupBilingualAliases(value: string, category?: string): string[]`.

### Task 2: Dropdown Option Matcher (`src/engine/dropdownMatcher.ts`)
- Implement `findBestOptionMatch(selectEl: HTMLSelectElement, targetValue: string, categoryHint?: string)`:
  - Filter out placeholder options (`-- Select --`, `0`, `""`, `Select District`, `নির্বাচন করুন`).
  - Compare `targetValue` against each `<option>`'s `text` and `value` using normalized string comparison and bilingual alias lookups.
  - Calculate confidence score.
  - Return `{ option: HTMLOptionElement, index: number, confidence: number } | null` (only if confidence $\ge 0.75$).

### Task 3: Select Setter (`src/engine/fieldSetter.ts`)
- Add `setNativeSelectValue(element: HTMLSelectElement, value: string)` using `HTMLSelectElement.prototype` descriptor setter and dispatching `focus`, `input`, `change`, `blur` bubbling events.

### Task 4: Tests
- Create `tests/engine/bilingualDictionaries.test.ts` testing alias resolution and Unicode normalization.
- Create `tests/engine/dropdownMatcher.test.ts` testing option selection, placeholder ignoring, and low-confidence rejections.

## Verification
- Run `npm run test` and verify all dictionary and dropdown matcher tests pass.
