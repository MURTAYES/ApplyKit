# Plan 02-01: Heuristic & Bilingual Field Matcher with Section Scoping

## Goal
Build the text normalization, DOM section scoping, and heuristic field matching pipeline that maps job application form inputs to profile keys with bilingual support (English/Bangla) and per-site mapping overrides.

## Must-Haves
- String normalizer supporting Unicode NFC normalization, ZWJ/ZWNJ stripping, Bengali numeral (`০-৯`) to ASCII (`0-9`) transliteration, and case-insensitive comparison.
- Section scoper that inspects ancestor elements (`<fieldset>`, `<legend>`, `<table>` headers, heading tags `h1-h6`, `.section-title`) to determine context (`basic_info`, `ssc`, `hsc`, `graduation`, `masters`, `present_address`, `permanent_address`, `job_experience`).
- Heuristic matcher with weighted scoring (`<label for>` 1.0 > enclosing `<label>` 0.95 > `aria-label` 0.90 > `placeholder` 0.80 > `name`/`id` 0.75 > adjacent text 0.70), 0.65 confidence threshold, and per-site exact selector overrides.
- 100% passing Vitest test suite for normalizer, section scoper, and matcher.

## Tasks

### Task 1: Bilingual Text & Digit Normalizer (`src/engine/normalizer.ts`)
- Implement `normalizeText(text: string): string`: NFC normalization, lowercase, punctuation removal, whitespace collapsing, ZWJ/ZWNJ removal (`\u200C`, `\u200D`, `\uFEFF`).
- Implement `bengaliToAsciiDigits(str: string): string`: converts `০-৯` to `0-9`.
- Implement `asciiToBengaliDigits(str: string): string`: converts `0-9` to `০-৯`.
- Implement `normalizeDateValue(dateStr: string, targetFormat?: string): string`: transforms `YYYY-MM-DD` and `DD/MM/YYYY`.
- Write unit tests in `tests/engine/normalizer.test.ts`.

### Task 2: Section Scoper (`src/engine/sectionScoper.ts`)
- Define section types (`SectionScope` = `basic_info` | `ssc` | `hsc` | `graduation` | `masters` | `present_address` | `permanent_address` | `job_experience` | `other_qualifications` | `unknown`).
- Implement `detectSectionScope(element: HTMLElement): SectionScope`:
  - Search upward for nearest `<fieldset>` with `<legend>`.
  - Search preceding siblings or parent containers for headings (`h1`–`h6`, `th`, `td.section-header`, `.section-title`, `caption`).
  - Match keywords in normalized text (e.g. "ssc", "dakhil", "secondary", "hsc", "higher secondary", "bachelor", "graduation", "masters", "present address", "permanent address", "experience").
- Write DOM-based unit tests with jsdom in `tests/engine/sectionScoper.test.ts`.

### Task 3: Alias Dictionary & Heuristic Matcher (`src/engine/matcher.ts`, `src/types/mapping.ts`)
- Define `FieldMatchResult` interface: `{ profileKey: string; confidence: number; source: string; section: SectionScope }`.
- Create comprehensive bilingual dictionary mapping aliases to profile keys:
  - English & Bangla name variations (`name`, `applicant's name`, `নাম`, `প্রার্থীর নাম`, `father`, `পিতার নাম`, `mother`, `মাতার নাম`).
  - Contact & identification (`nid`, `জাতীয় পরিচয়পত্র`, `mobile`, `phone`, `মোবাইল`, `email`, `ইমেইল`, `dob`, `date of birth`, `জন্ম তারিখ`).
  - Address fields (`care of`, `c/o`, `প্রযোজ্য`, `village`, `গ্রাম`, `road`, `road/street`, `post office`, `ডাকঘর`, `post code`, `পোস্ট কোড`).
  - Education fields scoped by section (`roll`, `roll no`, `রোল`, `reg`, `registration no`, `রেজিস্ট্রেশন`, `board`, `বোর্ড`, `passing year`, `year`, `পাশের সন`, `cgpa`, `gpa`, `result`, `ফলাফল`).
- Implement `matchField(element: HTMLInputElement | HTMLTextAreaElement, customMappings?: SiteMapping): FieldMatchResult | null`:
  - Check custom per-site selector map first (MATCH-05, MATCH-06).
  - Extract candidate texts from `<label for>`, enclosing `<label>`, `aria-label`, `placeholder`, `name`, `id`, adjacent header cells.
  - Determine section context via `detectSectionScope`.
  - Score matches against dictionary for candidate texts.
  - Return best match if confidence >= 0.65 (MATCH-04).
- Write unit tests covering diverse form layouts in `tests/engine/matcher.test.ts`.
