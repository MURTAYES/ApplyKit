# Phase 05 Plan 02: Privacy Verification, Code Hardening & Web Store Privacy Policy

**Phase:** 05-fill-report-live-portal-hardening
**Plan:** 02
**Requirements:** `PRIV-01`, `PRIV-02`, `PRIV-03`, `PRIV-04`

## Objective
Audit and harden the entire codebase against console PII leakage, verify complete DOM/JavaScript context isolation, and author a formal Chrome Web Store Privacy Policy document (`PRIVACY.md`).

## Tasks

### Task 1: Console Logging & Data Isolation Audit (`PRIV-01`, `PRIV-02`, `PRIV-03`)
- Audit all files in `src/` and `entrypoints/` to ensure no `console.log`, `console.info`, or `console.error` prints profile field values (names, NIDs, phone, email, etc.).
- Ensure all logging statements only report structural telemetry counts (e.g. `[Donna] 14 fields filled`).
- Confirm that profile data is strictly kept within extension closures and never attached to `window` or DOM element attributes.

### Task 2: Chrome Web Store Privacy Policy Document (`PRIVACY.md`) (`PRIV-04`)
- Create `PRIVACY.md` with:
  - Local-First Storage architecture (`chrome.storage.local`).
  - Strict no-tracking, no-analytics, and no-external-server guarantee.
  - Explanation of permissions (`storage`, `activeTab`, `scripting`).
  - User rights: Export, Import, and single-click Complete Data Deletion.

### Task 3: Privacy & Security Audit Automated Tests
- Create `tests/engine/privacyAndSafetyAudit.test.ts` scanning source files for forbidden logging patterns and validating `PRIVACY.md` compliance.
- Run complete test suite and build bundle.

## Verification
- Run `npm run test` (all tests pass).
- Run `npm run build` (clean extension build).
