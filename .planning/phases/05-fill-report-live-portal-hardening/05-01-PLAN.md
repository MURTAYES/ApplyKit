# Phase 05 Plan 01: Popup Fill Report Dashboard & Error UX

**Phase:** 05-fill-report-live-portal-hardening
**Plan:** 01
**Requirements:** `REPT-01`, `REPT-02`

## Objective
Enhance the extension popup UI to display a comprehensive fill telemetry dashboard (Filled, Skipped, and Unmatched metrics) after form filling, an expandable accordion for unmatched fields, and contextual error banners for restricted pages.

## Tasks

### Task 1: Popup State & Fill Report UI (`entrypoints/popup/App.tsx`)
- Add `report: FillReport | null` and `errorMessage: string | null` state.
- After fill execution completes, transition popup to report dashboard:
  - Metric 1: **Filled** (Emerald green badge, total count)
  - Metric 2: **Skipped** (Muted gray badge, total count)
  - Metric 3: **Unmatched** (Amber warning badge, total count)
- If `unmatchedCount > 0`, render an expandable `<details>` section listing each unmatched field label and section name (`REPT-02`).
- Add "Fill Again / Done" action to reset state.

### Task 2: Error Handling for Restricted Tabs & Injections
- Wrap `chrome.scripting.executeScript` and `chrome.tabs.sendMessage` in try/catch.
- Catch errors on `chrome://`, `edge://`, Chrome Web Store, or closed tabs.
- Display an inline warning banner explaining restricted page limitations.

### Task 3: Popup Styling (`entrypoints/popup/style.css`)
- Style the telemetry stat cards, status indicators, and unmatched fields list using Swiss Stark Minimal design tokens.

### Task 4: Tests
- Update `tests/popup.test.tsx` to verify metric card rendering, unmatched details accordion, and error handling.

## Verification
- Run `npm run test` and verify popup tests pass.
