# Phase 04 Plan 02: Mirror/Confirmation Fields & Qualifications Checkboxes/Radios

**Phase:** 04-address-logic-repeatable-job-experiences
**Plan:** 02
**Requirements:** `SPEC-03`, `SPEC-04`

## Objective
Implement pattern matching and auto-filling for mirror/confirmation fields ("Confirm Mobile Number", "Re-type Email", etc.), 3-state boolean checkbox/radio handling for Other Qualifications, and strict declaration/terms blacklist enforcement.

## Tasks

### Task 1: Mirror & Confirmation Field Matcher (`src/engine/matcher.ts`)
- Add confirmation regex patterns recognizing `confirm`, `re-enter`, `re-type`, `verify`, `পুনরায়`, `নিশ্চিত`.
- Map confirmation fields to primary keys:
  - `confirm phone` / `confirm mobile` $\rightarrow$ `basicInfo.phone`
  - `confirm email` $\rightarrow$ `basicInfo.email`
  - `confirm nid` / `confirm national id` $\rightarrow$ `basicInfo.nid`
- Ensure confirmation fields receive identical sanitized values without overwriting user data.

### Task 2: 3-State Checkbox/Radio Handlers & Safety Blacklist (`src/engine/fieldSetter.ts` & `src/engine/safety.ts`)
- Implement `setNativeCheckboxValue(element: HTMLInputElement, checked: boolean)`:
  - Safely sets `checked` state using native property setter and dispatches bubbling `click`, `input`, `change` events.
- Implement `setNativeRadioValue(radios: HTMLInputElement[], targetChoice: string | boolean)`:
  - Finds matching radio option ("Yes"/"No" / "হ্যাঁ"/"না" or matching value) and selects it.
- Update `safety.ts`:
  - Enforce declaration blacklist (`declare`, `certify`, `terms`, `condition`, `agree`, `consent`, `statement`, `শর্তাবলী`, `ঘোষণা`, `স্বীকার`, `captcha`).
  - Guarantee Donna never alters any declaration checkbox or CAPTCHA element (R4 constraint).

### Task 3: Other Qualifications Integration in FillEngine (`src/engine/fillEngine.ts`)
- Match `otherQualifications` fields (Computer Typing English, Computer Typing Bangla, Driving License, Extra Curricular, Computer Literacy).
- Support 3-state logic:
  - `true` $\rightarrow$ check / select "Yes"
  - `false` $\rightarrow$ uncheck / select "No"
  - `undefined`/unset $\rightarrow$ leave untouched

### Task 4: Tests
- Create `tests/engine/confirmationFields.test.ts` testing confirmation field matching and auto-filling.
- Create `tests/engine/qualificationsAndSafety.test.ts` testing 3-state checkbox/radio selection and declaration blacklist safety.
- Run complete test suite and build verification.

## Verification
- Run `npm run test` and verify all tests pass (covering 100% of Phase 4 requirements).
- Run `npm run build` and ensure extension compiles cleanly.
