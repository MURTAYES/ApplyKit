# Phase 04 Plan 01: Multi-Row Job Experiences & Direct Address Logic

**Phase:** 04-address-logic-repeatable-job-experiences
**Plan:** 01
**Requirements:** `SPEC-01`, `SPEC-02`

## Objective
Implement dynamic multi-row experience expansion (detecting "+ ADD MORE" buttons, dispatching click events $(N - M)$ times with DOM mutation synchronization) and per-row field resolution in profile order, along with direct permanent address population and `permanent_same_as_present` handling.

## Tasks

### Task 1: Multi-Row Job Experience Handler (`src/engine/repeatableSections.ts`)
- Implement `expandJobExperienceRows(rootElement: Document | HTMLElement, targetRowCount: number): Promise<number>`:
  - Identify Job Experience container / table.
  - Count existing experience row containers ($M$).
  - If $N > M$, locate the "+ Add More" / "Add Row" / "Add Experience" / "যোগ করুন" button or link inside or adjacent to the container.
  - Click the button $(N - M)$ times, awaiting DOM mutation (100–150ms per click) for each new row to appear.
  - Return the final count of available rows.
- Implement helper `getRowIndexForElement(el: HTMLElement, section: string): number`:
  - Determines the zero-based row index for an input/select inside repeated table rows (`<tr>`) or repeated div containers.

### Task 2: Address Mirroring & Direct Population (`src/engine/fillEngine.ts`)
- Enhance `resolveProfileValue` and address resolution:
  - If field is in `permanentAddress` section:
    - If `profile.permanentAddress` has values, use them directly.
    - If `profile.permanentAddress` is empty or if `permanent_same_as_present: true`, fall back directly to the corresponding `profile.presentAddress` value.
  - Never click any on-page "Same as present" checkbox (preserves form JS stability).
  - Sequence dependent selects for both present address and permanent address independently.

### Task 3: FillEngine Integration for Multi-Row Experiences
- In `executeFill`:
  - Run `expandJobExperienceRows` during initial setup.
  - When matching fields in `jobExperiences` section, use row index $i$ to resolve `profile.jobExperiences[i]`.
  - Fill designation, organization, employmentType, startDate, endDate, and responsibilities in order.

### Task 4: Tests
- Create `tests/engine/repeatableSections.test.ts` testing DOM row expansion and row indexing.
- Create `tests/engine/addressLogic.test.ts` testing independent present/permanent address fill and `permanent_same_as_present` mirroring.

## Verification
- Run `npm run test` to verify all repeatable section and address logic tests pass.
