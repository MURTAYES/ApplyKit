# Phase 06 Plan 02: Full HTML Reference Portal Fixture & Master Regression Suite

**Phase:** 06-reference-portal-mapping-test-suite
**Plan:** 02
**Requirements:** Quality & Hardening across all v1 requirements

## Objective
Create a standalone full-page reference portal HTML fixture replicating Teletalk Bangladesh government recruitment portals (`tests/fixtures/teletalk_application_form.html`) and author an exhaustive end-to-end regression test suite verifying 100% field accuracy and strict non-interference.

## Tasks

### Task 1: Comprehensive Reference Portal HTML Fixture (`tests/fixtures/teletalk_application_form.html`)
- Complete HTML document covering:
  - Header & post metadata.
  - Basic Information (bilingual name fields, DOB, NID/Birth/Passport toggle selects, mobile + confirm mobile).
  - Address tables (Present & Permanent with District and Upazila dependent dropdowns).
  - Education blocks (SSC, HSC, Graduation, Masters with If Applicable checkbox).
  - Multi-row Job Experience table with dynamic "+ Add More" row injection.
  - Other Qualifications (computer typing speed, driving license).
  - Declaration agreement checkbox (`#chk_declaration`) and CAPTCHA challenge block (`#captcha_code`).

### Task 2: Master End-to-End Regression Suite (`tests/engine/masterRegression.test.ts`)
- Load full HTML fixture from disk into JSDOM.
- Run `executeFill` with a complete applicant profile.
- Verify:
  - $\ge 95\%$ field fill rate across all sections.
  - Correct formatting for dates (`MM/DD/YYYY` or `YYYY-MM-DD` based on placeholders).
  - Proper cascading of District $\rightarrow$ Upazila in both present and permanent addresses.
  - Sequential multi-row experience expansion and filling in profile order.
  - Declaration checkbox remains untouched (`checked === false`).
  - CAPTCHA input remains untouched (`value === ''`).
  - User-typed values are strictly preserved (non-overwrite rule).

### Task 3: Complete Test Suite & Build Verification
- Run full test suite across all 6 phases.
- Run `npm run build` and ensure clean production build.
