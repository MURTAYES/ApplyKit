# Phase 06 Plan 01: Per-Site JSON Mapping Bundle & Auto-Resolver Engine

**Phase:** 06-reference-portal-mapping-test-suite
**Plan:** 01
**Requirements:** `MATCH-05`, `MATCH-06`

## Objective
Create the per-site mapping configuration for Teletalk Bangladesh recruitment portals (`src/mappings/teletalk.json`), implement the automatic URL-based site resolver (`src/engine/siteResolver.ts`), and integrate it into the fill execution pipeline.

## Tasks

### Task 1: Teletalk Site Mapping Bundle (`src/mappings/teletalk.json`)
- Define exact CSS selectors and profile key mappings for:
  - Basic Info: `p_name`, `p_name_ban`, `father_name`, `father_name_ban`, `mother_name`, `mother_name_ban`, `dob`, `gender`, `religion`, `marital_status`, `nid`, `breg`, `passport`, `mobile`, `confirm_mobile`, `email`, `quota`, `dept_status`.
  - Present Address: `present_care`, `present_village`, `present_district`, `present_thana`, `present_post`, `present_pcode`.
  - Permanent Address: `permanent_care`, `permanent_village`, `permanent_district`, `permanent_thana`, `permanent_post`, `permanent_pcode`.
  - SSC & HSC: `ssc_exam`, `ssc_board`, `ssc_roll`, `ssc_result`, `ssc_group`, `ssc_year`, `hsc_exam`, `hsc_board`, `hsc_roll`, `hsc_result`, `hsc_group`, `hsc_year`.
  - Graduation & Masters: `gra_exam`, `gra_subject`, `gra_institute`, `gra_result`, `gra_year`, `gra_duration`, `mas_exam`, `mas_subject`, `mas_institute`, `mas_result`, `mas_year`, `mas_duration`.

### Task 2: Site Resolver Engine (`src/engine/siteResolver.ts`)
- Implement `getMappingForUrl(url: string): SiteMapping | null`.
- Support glob / regex matching for Teletalk domains (`*.teletalk.com.bd`, `alljobs.teletalk.com.bd`).
- Integrate into `entrypoints/content.ts` to pass detected mapping into `executeFill(profile, document, siteMapping)`.

### Task 3: Unit & Integration Tests
- Create `tests/engine/siteResolver.test.ts` verifying URL resolution and selector mapping overrides.

## Verification
- Run `npm run test` to verify site resolver tests pass.
