<threat_model>
<threat_register>
| Threat ID | Category | Threat Description | Mitigation Strategy | ASVS Ref |
|-----------|----------|---------------------|---------------------|----------|
| T-01-01 | Elevation of Privilege | Extension requests broad host permissions (e.g. `<all_urls>`) violating store policies and user privacy | Restrict `manifest.permissions` in `wxt.config.ts` strictly to `storage`, `activeTab`, and `scripting` | V4 Access Control |
| T-01-02 | Tampering / DoS | Corrupted or malicious JSON profile import crashes extension or injects invalid structures | Validate imported JSON against Zod `ProfileSchema.safeParse()` before writing to `chrome.storage.local` | V5 Input Validation |
| T-01-03 | Information Disclosure | Plaintext profile data logged in browser consoles during debugging | Disallow `console.log` of raw profile objects across all storage and schema modules | V5 / Privacy |
</threat_register>
</threat_model>
